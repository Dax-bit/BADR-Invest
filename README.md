# BADR Invest

Mobile brokerage platform prototype for the Algerian stock market.

---

## Problem

Traditional brokerage systems require physical presence, manual verification, and paper-based workflows, making investment slow and inefficient.

---

## Solution

BADR Invest is a mobile-first brokerage system that digitizes the investment process, including:

- User onboarding
- KYC verification
- Bank account linking
- Portfolio management
- Order placement system

---

## Key Features

- Secure authentication system
- KYC workflow management
- Bank account integration
- Buy/Sell order system
- Portfolio tracking
- Market data visualization

---

## Software Engineering Work

- Requirements specification (functional & non-functional)
- Business rules definition
- UML modeling (use case, class, sequence, activity diagrams)
- Database design (SQLite)
- Object-oriented architecture
- Design patterns applied
